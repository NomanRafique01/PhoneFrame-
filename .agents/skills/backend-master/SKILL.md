# Backend Master — Orchestrator

**ANNOUNCE:** "Reading `backend-master` to route backend and full-stack implementation work."

**Core Rule:** Spec before code. Test before implementation. Responsive contracts mandatory for all UI data.

---

## 1. Mandatory Baselines

1. **Surgical Simplicity & YAGNI:** `karpathy-coder` (minimal blast radius, standard library first, zero speculative abstractions).
2. **Test-Driven Discipline:** `tdd-implementer` (write failing test first, witness failure, implement minimal code to pass).
3. **Responsive UI Contracts:** `responsive-contract-enforcer` (no hardcoded pixel sizes in API payloads, explicit aspect ratios and responsive srcsets).

---

## 2. Dedicated Backend Planning ($plan-backend)

When the user invokes `$plan-backend`:
1. Activate `backend-planner`.
2. Produce the complete Backend Architecture Blueprint: Domain entity glossary, responsive API schemas, tracer-bullet ticket dependency graph, and TDD plan.
3. Present to the user and request confirmation before touching code.

---
